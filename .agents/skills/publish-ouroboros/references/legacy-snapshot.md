# 历史 snapshot 分支约束

仅在任务明确更新 snapshot/v2.0.0-rc.1 且该发布任务仍适用时读取。不是其他版本或应用项目的通用发布要求；与当前任务不一致时按发布负责人明确的版本上下文处理，不借历史规则改写共享历史。

### `snapshot/v2.0.0-rc.1` 分支约束

- 原有特殊约束要求相对实际工作分支只保留 `bdf59a4c` 发版提交。该约束不能作为改写共享历史的许可；更新基线无法同时满足时停止，不自动重放或重置分支。
- 完整保留原提交消息，包括 `[web-image-tag:2.0.0-prerelease]`；不得重写已共享的原提交。
- 禁止新增空提交、重试提交或另一个发版提交。构建失败时重跑同一 ref 的流水线。
- 推送前核验工作分支是发版分支祖先，且 `git rev-list --count <baseline>..<target-branch>` 等于 `1`。
- 发现多余提交或目标与基线分叉时停止，向发布任务说明冲突；由该任务选择可保留历史的新发布 ref 或调整特定发布约束，不强推修复。
