# AI 自动化资产

本目录保存可复用的自动化方案、prompt 契约与实例参数示例。当前主题为 [GitLab 缺陷自动化](gitlab_defect_automation/README.md)：

- [DESIGN.md](gitlab_defect_automation/DESIGN.md)：方案边界、角色与状态协作。
- [GitLab 项目配置清单](gitlab_defect_automation/gitlab_project_setup.md)：可复用的配置步骤。
- [prompts](gitlab_defect_automation/prompts/README.md)：唯一 prompt 模板及参数、标签、表格列契约。
- [examples](gitlab_defect_automation/examples/README.md)：实例参数示例。

实例化时填写环境参数并生成最终 prompt，经人工审阅后再配置自动化；模板存在不表示自动化已经部署。单次实施计划、试运行结果和生成后的 prompt bundle 归关联任务或运行系统，不在此维护第二套规格或过程档案。
