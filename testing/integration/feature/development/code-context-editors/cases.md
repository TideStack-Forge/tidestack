# 用例

| ID | 分支 | 输入与通过标准 |
| --- | --- | --- |
| CCI-RPC-MODEL | normal/dependency | 生产 URL 控件补全 #{rpc. 的配置键、${customer. 的 name；method 只按配置 profile 补全；草稿完整 |
| CCI-RPC-AUTH | normal/boundary | HMAC secretKey 提供配置目录；token JSONPath $.data. 提供 accessToken，响应无 EL globals |
| CCI-BUSINESS-SCRIPTS | normal/state | beforeScript 的 $request. 显示 data；afterScript 的 $0. 显示 customer；多编辑器刷新不出现旧虚拟文档错误 |
| CCI-BUSINESS-LOG | normal/dependency | 生产 summaryTemplate 控件 ${Request. 显示 body，语言 freemarker |
