# 运行时逻辑流管理验收合同

对象是已部署逻辑流及其持久覆盖，固定名称、启用状态和对外输入输出合同。检查构建候选但不执行、不写库；保存执行集合 CAS、名称修订及 operationId 幂等；各实例通过正式 MetaProvider、Factory 与发布点独立应用。撤销写墓碑并恢复最后成功 Context 的默认。父子流整代切换，已捕获模型保持旧代次；失败保留旧完成态。

浏览器使用正式 AMIS schema 和同步进共享资源 JAR 的同一生产 UMD 包。列表/详情摘要不请求 canvas/debug/preview；点击图或编辑才请求 canvas。明确 runtime host 后引用目录不回落到 dev，智能提示与调试可关闭。失败有人工重试；只读禁止修改；保留旧版本目录可供旧页稍后加载。

本地边界：JDK 21、H2 TCP 共享存储、两个独立 JVM；MockMvc 只桥接 HTTP，身份为可信测试夹具，数据站通过正式测试 SPI 装配。它不能替代真实部署的认证链、代理配置、MySQL/PostgreSQL 方言或生产发布验收。

运行观测仅作用于当前应用，每个流程的监控和详细诊断默认关闭。策略使用统一配置 CAS，与模型修订独立。监控统计与诊断样本只接纳已启用流程，父子各自判定，默认无业务值。限时与容量有界，关闭后历史可读。验证双 JVM 的期望/采用修订、隔离、关联、重启和停止后计数不变，运行 `verify_observation.py --repo <worktree>` 并保存 JSON 证据。
