# 逻辑流在线调试集成契约

调试沿正式诊断 SPI、开发助手 MQBridge、共享调试仓储、私有通知及 HTTP 恢复、原编辑器 X6 画布路径执行。助手探测和控制必须绑定 appName、profile、运行时与助手进程身份；重建后的容器不得接管旧采集。缓存确认仅表示已接收，不表示持久化。

多活平台共用具备原子比较交换和 TTL 的仓储；默认 CacheManager 实现。命令和结果采用进程广播，事件采用固定具名竞争消费组，不能因平台副本数增加导致命令丢失或泄露其他用户数据。

测试不得重启或清理用户基础设施。Redis/RabbitMQ 端口显式传入；故障注入只允许带本任务标签的隔离容器。业务执行成功/失败结果在调试传输异常时保持一致；无法恢复的事件应显示不完整。所有资源必须有界。

进入调试保持原 Graph、节点、画布屏幕尺寸与位置、缩放、滚动和节点屏幕坐标；只在原浮动面板位置切换采集、执行与详情内容，复用编辑器面板和工具栏样式，并禁用节点移动/连线。选择执行、查看节点或异常、退出和恢复历史均不自动布局、居中、缩放或回写视口。用户仍可手动平移和缩放，退出保留当时视口；编辑面板、交互和样式恢复，已有撤销历史保留。运行标注不得写入模型或撤销栈。拓扑不兼容或其他流程调用时提示而不误标，事件详情仍可查看。
