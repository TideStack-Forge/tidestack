# RPC 工作区测试语义收敛修复

基线：`dev-next@c3ff611193`。范围：修复测试输入分析、配置驱动依赖快照、初始化构建检查与现有 RPC 字段语义的分叉。原执行器、SPI、模型 CRUD 和 VCS 仍是正式路径。本文件先记录方案，实际验收结果另行记录。

## 1. 修复目标与实现归属

1. `RpcModelTestInputs` 遍历完整模型和认证扩展字段，用 JSON Pointer 调用 `RpcFieldSemantics`。TEMPLATE 复用 ExpressionUtils/EL；CONFIGURATION 和 JSON_PATH 仅发现配置引用；NONE 不分析。配置键提取放入原 `RpcConfigurationTemplates`，与解析共享规则。
2. 将现有调用级配置读取前移为一次操作的配置视图，按覆盖值 → ConfigurationService → Environment 解析并记忆读取结果。SnapshotReader、认证构建和执行共用该视图。先解析认证引用、AccessToken 模式和令牌模型引用，再校验名称、读取当前应用 VCS 资源。revision 纳入资源内容、分支和实际依赖关系，不包含配置口令原值。
3. 初始化只分析字段、配置缺项、依赖完整性、循环和 SPI 支持性，不构造认证实例、不获取令牌、不发送目标请求。SPI 支持检查与实际构建共用原 Center 的选择逻辑。实际实例由执行阶段的原构建器创建，成功后进入同一执行链。

## 2. 初始化与执行合同

初始化统一为 `POST /api/dev/{appName}/rpc-model/{fullName}/test/init-form`，请求体仅允许 `configValues` 字符串映射。移除原 GET，所有调用方、权限用例及文档同步迁移。配置值不放 URL。

初始化返回模型摘要、revision、变量、配置项、缺失配置项及 ready。依赖配置缺失时返回已发现的输入，ready=false；保留填写能力，不以初始化异常阻断配置补全。禁用模型仍不可测试。初始化不回显默认配置原值。

覆盖值或覆盖开关修改确认后，前端立即使旧初始化失效并自动只读重建；期间禁测。用现有初始化代次丢弃旧响应，保留仍有效的输入，移除旧依赖输入。测试配置不参与模型 dirty。变量变化不触发依赖重建。模型 dirty 仍须先保存。

执行使用相同的准备流程，以当前 configValues 重读资源并核对 revision。依赖变化返回 RESOURCE_CHANGED，零次令牌和目标调用。依赖未就绪或输入无效同样零调用。普通配置值作为本次输入，按一次操作固定；不冒充模型版本。初始化重建后仍由用户点击运行测试。

## 3. 实施与验证顺序

1. 记录方案，补充行为复现测试。
2. 在现有字段分类、配置解析、Center、测试服务和 Drawer 状态中实施最小修复。
3. 验证组件、权限、前端状态、真实 AMIS Drawer 和原模态表单回归；执行后端编译、架构、覆盖率及前端构建/lint 检查。
4. 在隔离应用、数据库及端口上启动真实开发后端和主应用，使用可控目标 stub 完成配置缺失补全、依赖切换、初始化零调用、测试、保存和显式提交旅程；保存真实截图和实际请求记录。
5. 整理验收报告与证据，按实际结果给出结论，不以组件测试代替真实部署旅程。

## 4. 验收目标

| 编号 | 目标 | 判据 |
| --- | --- | --- |
| SEM-01 | 字段语义一致 | 完整模型配置键被发现；普通文本不被解释；JSONPath 不作为 SpEL |
| SEM-02 | 配置驱动依赖 | 配置可切换认证、静态/动态令牌及令牌模型；只读当前应用资源 |
| SEM-03 | 初始化无调用 | 缺配置仍可填写；初始化零令牌、零目标调用；默认秘密不回显 |
| SEM-04 | 快照与隔离 | 旧依赖 revision 零调用；同次配置一致；应用与并发测试互不污染 |
| SEM-05 | 前端一致性 | 覆盖更改触发重建；旧响应不能启用测试；模型 dirty 与测试配置分离 |
| SEM-06 | 原功能回归 | 保存零 commit；显式提交必填信息并正确关闭；原执行与弹窗通过 |
