# ouroboros-app-runtime 模块设计摘要

## 模块定位

`ouroboros-app-runtime` 是能力层中的应用运行时承载模块，负责为上层应用提供生命周期管理、系统信息、缓存、分布式 ID、脚本上下文和一组运行时插件能力。它更像“应用运行环境承载器”，而不是某个独立业务功能包。

## 责任边界

该模块负责把多个能力模块和平台基础设施组织成应用级运行时支撑，不负责具体业务模块实现，也不负责平台最终交付入口本身。它可以为平台应用准备运行环境，但不应重新定义安全、配置、通知或组织结构的核心语义。

## 依赖关系

它虽是单模块，但依赖面很广：`pom.xml` 明确依赖配置、安全、UI、组织结构、通知、业务日志、消息队列、缓存与 Redis 等能力，是“能力装配节点”，为上层应用把多个基础能力收口到同一运行时环境中。新增通用能力前，应先判断是否应该下沉到更专门的 `ability` 模块。

## 演进状态

`ouroboros-app-runtime` 已经承担了明显的“运行时收口层”角色，后续最需要警惕的是职责继续膨胀。维护者应优先把它理解为装配和承载层，而不是把所有应用级通用能力继续堆进单个模块。
