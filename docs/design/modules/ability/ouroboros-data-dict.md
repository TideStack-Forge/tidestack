# ouroboros-data-dict 模块设计摘要

## 模块定位

`ouroboros-data-dict` 是能力层中的统一数据字典能力，负责沉淀字典定义、字典项结构、运行时查询与开发时管理入口。它更接近“平台级基础数据语义服务”，为字段选项、状态值和低代码配置提供统一字典来源，而不是承载某个业务域自己的主数据。

## 责任边界

该模块负责字典与字典项的模型抽象、树形与扁平结构转换、运行时读写服务以及开发平台中的字典维护入口，不负责替代业务数据模型本身，也不负责定义具体业务对象之间的关系。维护时要避免把“业务主数据管理”或“页面级选项逻辑”继续塞回本模块。

## 依赖关系

模块分为 `core`、`runtime`、`dev` 三层：`core` 提供字典抽象与序列化模型，`runtime` 提供控制器、服务和 value type 集成，`dev` 通过 `@DevelopModule("data-dict")` 与版本控制文件检查器接入开发平台。它向下依赖通用模型、序列化和开发支撑，向上则被字段类型、低代码管理界面和运行时配置消费。
