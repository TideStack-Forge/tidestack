# 应用开发看板

应用开发看板帮助开发者理解应用内各类能力的分工、投射与调用方向，并进入对应开发功能。页面由既有 `DevAppDashboard` renderer 承载，通过能力关系和功能矩阵两个 Tab 提供系统总览与功能入口。

## 页面结构与交互

页面沿用前端基座的侧栏、调试工具栏、应用页签、字体和 AMIS 线形 Tab。看板顶部显示应用图标、标题、名称与最近提交，并提供配置项、扩展包、应用配置、版本管理及编辑权限入口。编辑权限入口读取既有 `canManageEditAccess` 权限。

| 区域 | 展示与操作 |
| --- | --- |
| 能力关系 | 显示业务模型及相关能力，线路表达投射、调用和依赖。单击节点或关系显示底部详情，双击节点或点击详情按钮进入功能。 |
| 功能矩阵 | 按开发菜单的分类展示功能入口，点击后通过宿主菜单机制导航。独立菜单入口置于分类卡片上方。 |
| 搜索 | 搜索能力名称、说明或菜单路径。业务模型的六项要素参与能力搜索，矩阵可按分类和入口名称查找。 |
| 流动动画 | 控制能力关系上的方向光点，线路持续显示。遵守系统减少动态效果设置。 |
| 可视化建模入口 | 业务模型详情可直接打开业务模型页的可视化建模 Tab，使用 `?view=visual-modeling` 和 AMIS `activeKey`。 |

顶部操作区按整组换行。看板吸收工作区可用高度，能力图垂直居中，详情栏位于底部，矩阵卡片按行等高展开。关系图最小宽度为 800px，图面高度为 396px。较窄空间通过图内横向滚动保持节点比例，较矮窗口通过内容区滚动访问完整内容。

## 能力分层与关系方向

能力图以业务模型为核心，展示 16 个节点和 15 条关系。用户可见的界面和导航位于上层，业务服务位于中层，数据与权限位于下层。左侧放业务模型及其组织、导航和权限，中央放 UI、WebAPI、逻辑流、数据模型，右侧放承载、集成及依赖能力。配置项与扩展包位于顶部工具区。

业务模型节点分两行展示属性、关系、视图、动作、事件和访问权限，详情采用相同用语。

| 关系类型 | 来源 | 目标 |
| --- | --- | --- |
| 投射 | 业务模型 | UI 模型、WebAPI 模型、逻辑流、数据模型、模块树、菜单模型、权限模型 |
| 调用 | 逻辑流 | 消息通知、RPC 模型、消息队列生产端 |
| 调用 | 消息队列消费端、计划任务 | 逻辑流 |
| 依赖 | UI 模型 | 微前端、低码界面 |
| 依赖 | 数据模型 | 数据字典 |

光点沿来源到目标移动，线端省略箭头。消息队列生产端与消费端分别标注角色，并在关系说明中保留方向。该图维护平台能力关系，具体应用内业务对象之间的关系由[业务模型关系画布](../core/ouroboros-business-model.md#开发态业务模型关系画布)展示。

## 印刷电路视觉

节点采用浅色底、细边框和轻微内描边。业务模型节点拥有四边淡色引脚，长度 4px、节距 12px，默认不透明度 28%，选中为 40%。其他节点保留普通边框。

线路采用水平、竖直与 45 度斜线段组合，通过分配连接端口和并行通道减少交叉、节点穿越及直角转弯。走线保存在同一拓扑定义中，宽度变化时由电路组件调整几何位置，保持斜段角度和通道次序。

| 视觉项 | 当前取值 |
| --- | --- |
| 线路宽度 | 3.5px，使用 `non-scaling-stroke` 保持印刷走线厚度 |
| 线路不透明度 | 默认 30%，相关选中 50%，悬停或键盘聚焦 72% |
| 关系命中区 | 14px 透明描边，支持鼠标和键盘选择 |
| 投射、调用、依赖 | 分别使用 `#618CBC`、`#579CAB`、`#8199B1` |
| 引脚 | `#88A6CB`，仅用于业务模型 |

配色延续 Logo 的青色 `#00D2E9`、天蓝 `#00A1E9` 和深蓝 `#0057E4`。Tab、按钮、选择和焦点继续读取基座主题变量，图内分层使用以下色板。图例和标签文字独立加深，确保淡色线路下文字仍清晰。

| 层级 | 节点浅底 | 边框 | 强调色 |
| --- | --- | --- | --- |
| 业务模型 | `#EDF4FF` | `#A8C4EC` | `#356AB2` |
| 界面与导航 | `#F0F8FC` | `#BAD7E7` | `#2879A6` |
| 服务与集成 | `#F0F9FA` | `#BBD9DF` | `#287E91` |
| 数据与权限 | `#F3F6FA` | `#C6D3E2` | `#55718E` |

## 功能矩阵与导航来源

功能矩阵通过正式 `dev-workspace-menu` 接口获取当前应用的菜单树，继承分类、名称、图标、顺序、路径和 `showMode`，使用宿主 `openMenuItem` 打开入口。多级入口保留完整路径，缺少图标时使用现有菜单默认图标。

当前菜单分类包括数据与模型、界面设计、业务逻辑、组织架构、系统集成、基础配置、应用管理、运维监控和高级功能，业务模型与统计分析为独立入口。实际分类与数量随正式菜单定义和可见范围变化，矩阵从接口结果构建。能力图同样从已返回菜单解析可用导航，无法解析的入口禁用并给出状态。

## 实现入口与验证方式

| 入口 | 职责 |
| --- | --- |
| [dashboard.ui-schema.json](../../../../dev-module/ouroboros-dev-app-management/src/main/metadata/dev/{appName}/dashboard.ui-schema.json) | AMIS 页面、应用上下文和编辑权限接入 |
| [DevAppDashboard.tsx](../../../../frontends/web/ouroboros-amis-runtime/src/renderers/DevAppDashboard.tsx) | 数据加载、两个 Tab、搜索、详情和宿主导航 |
| [dev-app-dashboard.ts](../../../../frontends/web/ouroboros-amis-runtime/src/renderers/dev-app-dashboard.ts) | 能力拓扑、走线、分层和菜单目录构建 |
| [DevAppDashboardCircuit.tsx](../../../../frontends/web/ouroboros-amis-runtime/src/renderers/DevAppDashboardCircuit.tsx) | 电路几何、关系选择及方向动画 |
| [DevAppDashboard.scss](../../../../frontends/web/ouroboros-amis-runtime/src/renderers/DevAppDashboard.scss) | 布局、配色、引脚及响应式样式 |
| [看板行为测试](../../../../frontends/web/main-app/tests/unit/src/components/amis/renderers/dev-app-dashboard.test.js) | 菜单目录、搜索、关系方向、走线几何与渲染交互 |

视觉回归应覆盖能力关系、功能矩阵、节点与关系详情、动画关闭、减少动态效果和较窄窗口。核对节点层级、六项业务要素、方向、走线形状、仅业务模型引脚、菜单图标与名称以及满高布局。测试数据中的入口数量和截图尺寸属于各次任务证据，随验收基线记录。

当前实现已有页面和行为测试资产，真实部署的完整权限、导航和页面生命周期仍需目标环境验收。协同及存储的未闭合范围由[模型实时协同](../../cross-cutting/model-collaboration.md#当前边界与演进)维护。

当前能力、启用条件和实现入口见[开发平台特性地图](../../../features/development.md)。
